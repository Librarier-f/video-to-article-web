# 自定义 API 与 Markdown 预览实施计划

目标：在现有页面内补齐自定义 OpenAI 兼容配置和可阅读的 Markdown 预览，沿用既有界面风格。

设计：设置中保存 Base URL、API Key 和模型名；输入页选择自定义后加载并允许临时覆盖。配置只在浏览器保存，Key 仅随请求临时传递。后端统一处理接口前缀和完整 chat/completions 地址，校验配置。Markdown 标签默认渲染 Markdown，支持切换源码、复制和下载；用 react-markdown + remark-gfm 解析，不执行正文中的 HTML 脚本。

实现步骤：

- [x] 先补 API 地址规范化及自定义请求的回归测试，验证失败，再实现后端地址处理和配置校验。
- [x] 设置面板增加自定义配置；输入页加载配置，提交时只为自定义供应商携带覆盖值。
- [x] 新增独立 Markdown 渲染组件与样式；接入预览/源码切换，保留下载和复制。
- [x] 验证 Markdown 标题、表格、代码、链接、图片及不可信 HTML 的处理；运行前端构建和后端回归测试。

验证：18 项后端测试、5 项前端测试及生产构建通过；浏览器确认配置保存、同步与刷新恢复。接口测试使用模拟服务，未验证实际供应商连通性。

边界：不扩展到非 OpenAI 兼容协议；不添加新的视觉模型配置；不改动此前性能优化的行为。
