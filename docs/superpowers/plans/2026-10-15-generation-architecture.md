# 生成链路重构计划

目标：减少模型请求和串行依赖，缩短首次可读正文时间，保留现有自定义接口、HTML/MD、卡片及多模态功能。

设计：默认 fast 路径对 12000 字以内字幕一次生成正文和卡片；更长字幕按 12000 字块并行提炼，再合成为完整正文和卡片。deep 路径保留现有逐章扩写。截图补充与正文并行，正文就绪立即保存并通过 article_id 通知前端，增强完成后更新同一文章；附属失败不丢失正文。下载仅提取视频元数据并选择一条字幕轨道。HTTP 客户端在同一任务中复用。

- [x] 建立快速路径调用次数、完整输入、失败清理、正文优先保存及增强容错回归测试。
- [x] 实现自适应生成策略与任务内连接复用，保留深度路径兼容。
- [x] 解耦视觉和卡片增强，发布正文与前端提前预览，修复轮询并发合并。
- [x] 精简字幕提取和关键帧抽取，记录可比较的阶段耗时。
- [x] 运行后端/前端测试与生产构建，离线比较请求次数、首次正文及完成耗时，明确真实模型性能仍需实测。

质量边界：快速模式采用信息密度优先的篇幅；深度模式保留逐章扩写要求。模拟基准只衡量调度和调用拓扑，不能替代真实生成质量与时延评估。
