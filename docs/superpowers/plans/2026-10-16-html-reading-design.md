# HTML 阅读模板升级

设计定位：视频知识长文的数字出版物，保留五套主题名称、风格和内容来源。DESIGN_VARIANCE=6，MOTION_INTENSITY=3，VISUAL_DENSITY=3。使用原生 CSS 与少量原生 JavaScript，所有资源内嵌，字体采用本地系统字体，不增加 AI 调用或图片生成。

现状：五份模板重复大量 CSS；HTML 与 MD 共享线性正文，缺少目录、阅读控制与媒体交互；旧文章存储完整 HTML，仅修改模板不会生效。

交付：

- 共享阅读骨架、五套主题：深色沉浸、蓝白报告、赭石书刊、暗色技术、极简现代；统一正文宽度、标题层级、引用、表格、代码与图注。
- 后端生成标题锚点、目录、真实阅读时长与文本摘句；桌面固定目录、移动端折叠目录。
- 自包含的字号调整、明暗切换、专注阅读、图片原图查看、代码复制、打印样式；禁用脚本时仍可阅读全文和使用目录。
- 历史文章在读取和导出时按原主题套用新模板，不调用模型、不批量覆盖数据库正文；MD 导出保持正文内容。
- HTML 导出内嵌可访问的本地截图，预览中修正截图 API 地址。原视频缩略图仍以实际来源呈现，不插入无关装饰图片。
- 补渲染、旧模板提取、主题、元数据转义、离线导出测试，运行后端回归与前端构建；浏览器验证桌面/移动端与交互。

验证记录：后端 42 项回归、前端 8 项测试与 TypeScript/Vite 生产构建通过。浏览器实际查看五套主题，在 390px 移动视口验证目录折叠和跳转、表格布局且无页面横向溢出；交互验证字号调整、深浅色切换、专注阅读及代码复制。审查发现并修复旧正文锚点失效和深色主题打印配色覆盖问题，另修复历史正文重复包装表格的问题。未使用付费模型重新生成文章；未做 Lighthouse 评分或实体打印测试。
